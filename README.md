map: lo use en pintarLista para hacer el li de cada tarea.

filter: lo use en tareasVisibles para el filtro y el buscador, y en eliminarTarea para quitar la tarea del arreglo.

reduce: lo use en actualizarResumen para contar las tareas completadas.

sort: lo use en tareasVisibles para que las tareas nuevas salgan arriba.
